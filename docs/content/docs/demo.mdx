Choose an **Example** or adjust the controls below the preview. Expand and sort the history, switch languages, and use the site's theme switch to try light and dark mode.

<ChangelogDemo />

**Language** changes both labels and dates. **Start expanded** sets the initial open state; you can also open and close the history directly in the preview. **Empty history** shows the empty state, while disabling both sections hides them. **Reset** restores the selected example, including its expansion and sort order.

The preview uses a saved snapshot of [this project's Git history](https://github.com/shenxianovo/fumadocs-page-history/commits/main/docs/content/docs/index.mdx), with [shenxianovo's GitHub profile](https://github.com/shenxianovo). The **Co-authors** example adds an illustrative author with a longer name and no avatar. No GitHub token is needed to view it.
